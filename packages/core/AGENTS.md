# Core ownership

Pure deterministic selection and validation live here. No database, HTTP, provider, or UI imports. As of ADR-0028/#114 the Composer is `composer-signals-v1`: a versioned, immutable policy scores and diversity-ranks a signal snapshot (exposure count/recency, unread, source — nothing else) fetched by the caller (`packages/db/src/composer-signals.ts`) and renders one registered explanation per candidate; the caller persists that same output as `decision_signal` rows so a later reader can recompute and check it rather than trust it. Do not describe this as the target design's full multi-term utility engine — it is a deliberately smaller, SQL-primitive ranking (ADR-0028). Add cognitive utility, provenance and uncertainty through a further Composer issue and target design when one exists. Changing ranking requires a new policy version and journey evidence, never a code-constant edit to the scoring function.
