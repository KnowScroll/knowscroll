# Editorial starting library

Three real, hand-selected sourced Scrolls for the bootstrap journey; not generated output or test fixtures. NASA pages were checked on 2026-09-15. Prose is original paraphrase; source links support the factual statements. The reflection prompts are invitations, not asserted learning results. The library is deliberately small and exhaustion is shown honestly. Astronomy content is unrelated to the semantic meanings of planets and Stars in a personal universe. Broader inventory and interactive blocks remain product work.

Changing published text requires a new asset revision and provenance migration. The seed command never overwrites an existing asset.

Model-written Scrolls (ADR-0041) are not here: they live only in the database, written by `scripts/scrolls/write-scrolls.ts` from allowlisted public-domain pages and admitted by deterministic checks. No model text is committed to Git.
