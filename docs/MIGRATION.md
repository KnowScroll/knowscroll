# Foundation migration

Selected sources are recorded with SHA-256 in [migration-manifest.json](migration-manifest.json). Original files were read/copied without modification.

| Material | Treatment |
|---|---|
| Founding product definition | Full scope adopted, with current authority overlay |
| Refined core-engine 00–25 | Coherent detailed target suite; original proposal metadata preserved |
| Sep 15 critical/runtime research | Historical source snapshots, not live compatibility claims |
| Legacy decisions | Archive; new ADRs own this repository |
| Cosmos + Living Observatory | Visual/behavior references, not application implementation |
| Legacy web app, SQLite migrations, steering hooks | Not migrated; new Android/PostgreSQL implementation is intentional |
| Cutroom implementation and video-harness design corpus | Not migrated; separately owned upstream HTTP contract |
| Other design experiments and old generated artifacts | Remain in original repository; not current authority |

The old owner-and-friends focus remains the first product audience. Preserving a full target does not prove capacity for 10,000 users; load, fairness and cost need measured evidence. No source has been silently promoted into runtime proof.
