# J003 — Clear private Scroll history

J003 runs against one disposable loopback PostgreSQL database with real API and worker processes. It creates two A devices and an independent B universe, proves both histories are nonempty, clears A through `POST /v1/history/clear`, then verifies A's other device is rejected while B and the shared library survive unchanged.

It deliberately withholds the first successful clear response, retries the identical body for the same receipt, admits new A activity, and proves that replay does not erase that newer activity. A distinct stale request gets 409. The worker starts after the clear to prove deleted old work cannot restore A history, then projects a fresh current-epoch keep.

```sh
. ./scripts/env.sh
pnpm exec tsx scripts/run-isolated-history-journey.ts
```

The receipt contains non-secret IDs, row counts, source hashes, and clear metadata. It does not contain bearer tokens, deleted payloads, or provider credentials. This is evidence for the bounded bootstrap-history control, not account deletion, backup erasure, public identity recovery, or semantic-world reset.
