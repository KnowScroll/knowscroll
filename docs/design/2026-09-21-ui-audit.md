## Bugs and production polish

- A1 is reproduced, not speculative. Native bounds include `[968,1094][1080,1241]` for a body
  intended to have full 147px width, with title clipping. Earlier tests did not prevent this.
- W1 is reproduced: Keep leaves screen unchanged and focuses Trace 1.
- Both System implementations put unrestricted source titles and actions directly around an orbit;
  many worlds/long titles require a bounded fallback, not overlapping absolute positions.
- Native source sheet opens and Android Back returns to reading; preserve it.
- Working foundations to preserve: source/claim access, truth pills, privacy epochs, same-key retries,
  visible exposure boundary, original Trace revisit, finite-library rest, existing provider fencing.
- No eligible real Reels, semantic galaxy evolution, production web auth, rooms or social were
  demonstrated. These are release gaps, not things a CSS pass can prove.
- Reference CSS and docs contain prior contradictory reductions. This successor permits a local
  world inspection from existing `WorldSummary` facts and atmospheric decorative rendering, without
  introducing a new domain entity, derivation method or backend mutation.

## Implementation decisions

- Keep is a separate web collection using freshly reconciled existing Universe/Trace responses.
- Atlas includes System and local World inspection. World detail uses only source title/URL and
  exact encountered/total Scroll counts; it creates no new domain model or events.
- Coastline, grid and cloud textures are decorative (aria-hidden), never named semantic regions.
- Reference fonts are distributed locally with OFL licenses. Google Fonts upstream links and
  copyright texts are in `apps/web/public/fonts/`; the same binaries are used by Android.
- `FULLY EXPLORED` is replaced by literal encounter language. Age no longer enlarges saved Traces.
- System entry remains available with zero keeps: no saved items is not evidence of no encounters.
- Narrow/short web Atlas uses bounded flowing rows so its labels and navigation remain reachable.
- Existing sheet/source, retry, privacy-epoch and visible exposure rules remain authoritative.
