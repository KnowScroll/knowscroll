KnowScroll — product design v2.1 (export of the Design canvas, 19 Oct 2026)

index.html   Start here. Links to every artboard, grouped by canvas page.
html/        50 static artboard pages, plus Prototype-storyboard.html (every step
             of the four clickable journeys). Open them in a browser with an internet
             connection so the fonts load (Bricolage Grotesque, Instrument Sans, DM Mono).
             Without it they fall back to system fonts.
source/      Editable sources: canvas.json (layout, pages, frame sizes) and one
             .dc.html per artboard. They need the canvas runtime to render, so they
             won't display correctly when opened directly.

The prototype is static in this export. Use Play on the canvas for the clickable version.
All people, content and worlds are authored design examples, not product activity.
