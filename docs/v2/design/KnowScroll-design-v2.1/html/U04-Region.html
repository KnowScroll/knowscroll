U04

Regions & topic card

A region opens a compact card with one encounter. Open goes straight in; returning lands on the exact same spot with the ship parked.

Prototype · design data

Route & origin

/universe/ml/inference/deployment from a pin tap in U03 or list view row. Open → /e/:id?from=region; back returns to this route with the stored camera.

Actions

Primary: Open the region’s encounter. Secondary: Close card, “More in Deployment” (more encounters from this region in Explore), pick another pin. The card never lists sources, badges or counts.

States & overlays

card open · encounter entry (paper register, breadcrumb chip) · exact return (ring + status line) · encounter unavailable (card says so; region stays) · offline (card shows “Opens when you’re back online”).

Commands · observations

OBS universe.select{region} · universe.open_encounter · universe.return
None of these are content evidence; only the encounter’s own playback/reading observations are.

Restore

Camera {system, planet, region, zoom, rotation} and the encounter’s playhead are stored separately. Return re-selects the pin, parks the ship and closes the card so the map is visible.

Accessibility & platform

Card is a labelled dialog; focus moves to its title, Esc / back closes it and returns focus to the pin. Tab through pins in list order; Enter opens. Screen readers can use U02 list view throughout.
