E03

Interactive block gallery

Approved block types inside “Attention, slowly”. Each block says whether it captures gestures, has a text alternative and keeps its own state per article revision.

Prototype · design data

Route & origin

Blocks live inside /s/:id; each has an immutable blockId and a versioned type (diagram.v1, compare.v1, slider.v1, disclosure.v1, code.v1). Parameters are bounded; no arbitrary model HTML or JS ever runs.

Actions

Drag the word · Reset · Describe · move the slider · expand or collapse · copy code · switch to the text version. Each block declares captures gesture yes/no; the article never steals a gesture a block has claimed.

States & overlays

idle · interacting (yellow ring only; no ownership wording in the UI) · expanded/collapsed · copied (button reads “Copied”) · text version · render fallback (E02-4) · revision changed (state reset with notice).

Commands · observations

OBS scroll.block_interaction{blockId, kind} — deliberate interaction only, summarised; no raw pointer frames
OBS scroll.block_coverage{blockId}

Restore

Block state (slider value, word position, expanded) persists by article revision + blockId and comes back after Share/Ask/back. A new revision needs an explicit compatible migration, otherwise the block resets and says so.

Accessibility & platform

Slider: arrow keys change it by one step, Home/End jump to the ends, valuetext is spoken. The diagram has an aria-label and a table alternative. Code is focusable for keyboard scrolling. Tab order follows reading order. Native: the slider uses a gesture handler that wins against vertical scroll only after the horizontal axis is locked.
