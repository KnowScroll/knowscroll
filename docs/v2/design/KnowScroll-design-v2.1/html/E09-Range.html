E09

Content range

Same controls, different characters. The rail, the Reel/Scroll switch, the edge tab and the nav never move; the content inside brings its own palette, imagery, rhythm and motion.

Prototype · design data

Route & origin

Same routes as every encounter: /e/:id (Reel), /s/:id (Scroll). Content character comes from the asset (illustration, palette, caption style, block set), never from a different screen template or chrome.

Actions

Fixed everywhere: rail order Like · Save · Share · Ask; Reel/Scroll switch top-right; right-edge tab with → (Part solid yellow, Related dashed cream); nav pill at the bottom. Editorial Scrolls hide the nav while reading, like E02.

States & overlays

Narrated Reels: captions follow narration, italic for voice-over. Kinetic captions: one highlighted chunk at a time. Editorial: drop cap + figure with caption. Comparison: input, stepper, result cards. All share E01/E02 loading, offline, corrected and unavailable states.

Commands · observations

OBS reel.visible_interval · reel.captions_toggled
OBS scroll.block_coverage · scroll.block_interaction{block: weight-compare}
CMD encounter.save · thread.continue{series|related} · format.switch

Restore

Reels: playhead. Editorial Scroll: anchor paragraph. Comparison Scroll: block state (the weight you entered) stored per article revision + block ID; it reappears when you return and in any shared snippet that includes the configuration.

Accessibility & platform

Captions on narration and kinetic text are real text, not burned in. Football motion has a reduced-motion still with numbered arrows. Figures carry alt text. Weight input has a label, numeric keyboard on native, stepper buttons and announced results.
