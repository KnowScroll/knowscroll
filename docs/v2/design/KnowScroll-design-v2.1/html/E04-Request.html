E04

Topic / content request

An optional one-shot ask, not a chatbot. What you ask for right now overrides any plan straight away; if nothing fits yet, the feed carries on quietly.

Prototype · design data

Route & origin

Sheet over /explore or /s/:id, opened by Ask on the action rail or strip. It is never the home screen and never a chat transcript.

Actions

Primary: Send request. Secondary: format (Reel / Scroll / Either), scope (About this / Something new), Cancel on the chip, nearest-options links. Voice input is optional and outside the initial scope.

States & overlays

draft · sending · accepted → ready now (shown immediately) · accepted → pending chip (E07 component) · ready later (non-interrupting notice, E06-3) · unavailable (closed, with reason) · cancelled (chip disappears, no toast) · offline (Send disabled with banner).

Commands · observations

CMD request.topic{text, format, scope, requestId} · request.cancel{requestId}
OBS request.sheet_opened · request.sheet_dismissed

Restore

The Reel underneath stays paused at its second while the sheet is open and resumes paused on close. An unsent draft is kept for this session only. Current intent overrides the plan at once; the long-lived universe doesn’t change because of an ask.

Accessibility & platform

The field is focused on open; format and scope are radio groups. Web: Enter sends, Esc closes, focus returns to Ask. Native: the keyboard pushes the sheet up and the back gesture closes it. The status chip is announced politely; Cancel has its own label.
