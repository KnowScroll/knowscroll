H02

Share landing & invitation

What a shared link opens on the web or in the app. The link resolves to a current access decision for one exact revision; private links reveal nothing — not even a title — until access is checked.

Prototype · design data

Route & origin

/share/:token from any external app, email or chat. Resolves server-side to the current access decision for one exact revision + optional anchor. Universal link opens the app when installed, else this web page (React Native Web).

Actions

Primary: Watch / Open Reel / Sign in. Secondary: Open in the app, Reply in Talk, Sign in to keep it. Revoked and withdrawn states offer only a neutral way into the product.

States & overlays

public signed-out · private access-required · available (authorised) · expired/revoked by sender · withdrawn content · corrected since shared. Open Graph/preview metadata exists only for public links; private previews are blank.

Commands · observations

OBS share.landing_viewed{state} · share.open_in_app
CMD encounter.save (after sign-in)
Opening the card starts Ravi’s own exposure; receiving it gives no consumption credit.

Restore

After sign-in the user returns to this exact landing, then into the Reel at the shared anchor (0:12). The corrected state opens the newest revision and says so; it never silently presents the old one.

Accessibility & platform

Real page headings; Watch is a labelled button; no autoplay with sound. Web: works without the app and without JS-heavy chrome. Native: deep link lands in E01 with the same anchor. No private data in page title or meta tags.
