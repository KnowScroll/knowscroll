X03

Exploring a branch

Opening a branch swaps the navigator for the branch’s own items and keeps a one-tap way back to the original sequence at your position. Discussion can stay in the branch or the whole thread.

Prototype · design data

Route & origin

/t/:threadId/b/:branchId/:item from a branch card (X02) or the map (X04). The return chip always names the destination: the original sequence at your last position.

Actions

Primary: watch/read branch items; return to the original. Secondary: discuss in branch or whole thread, try another assumption, share a moment from the branch, open a perspective.

States & overlays

branch item ready · next item preparing (explicit) · speculative banner persistent on every item · branch removed by creator (return chip only) · discussion empty · offline (cached item plays, chat queued).

Commands · observations

CMD branch.open{branchId} · thread.return{threadId}
OBS reel.visible_interval{branchId} · scroll.block_coverage
CMD message.send{scope: branch|thread}
Branch content feeds only the viewer’s own universe.

Restore

Back stack: original Part 2 @0:18 → branch item 1 @0:14. Back (or the return chip) pops to Part 2 paused at 0:18. Each person keeps a separate position per branch; nobody is pulled along.

Accessibility & platform

Return chip is the first focusable item after the title and reads “Back to Black holes, Part 2 at 0:18”. Speculative banner is text. Native back edge and web Back do the same as the chip. Desktop: branch items replace the navigator column (D03).
