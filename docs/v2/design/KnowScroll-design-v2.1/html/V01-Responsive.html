Responsive & accessibility variants

Same components, re-composed per size. Nothing truncates at larger text; every motion has a reduced form; every swipe has a button and a key.

Prototype · design data

Breakpoints & layout rules

≤360 compact: icon-only nav, 44px rail. 361–599 phone: floating pill nav. 600–1023 tablet: nav rail + one side panel (thread, outline or conversation). ≥1024 desktop: rail + content + side panel, one active player.

Keyboard & screen reader

Every swipe has a key and a visible button (↑↓ subject, ←→ thread, Space play). Focus order: top bar → content → actions → thread → nav. Landmarks: nav, main, aside. Universe always has the list view outline.

Platform differences

RN native: system share sheet, back edge = Back (one step through your own history, N01), haptics on Save. RN Web: Web Share with copy-link fallback, text selection in Scrolls, browser history entries, hover tooltips for icon buttons.
