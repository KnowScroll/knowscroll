Same ML, three people

Asha, Ravi and Meera have each explored Machine learning. All three read as ML (teal oceans, angular land, the same star, octagon regions), but coastline, material, light, landmarks, region layout and neighbours are personal. Cover the name: can you still tell them apart?

Prototype · design data

Shared family cues (never vary)

Teal ocean hue family · angular, outlined land · one organising star with the same core and glow · octagon region pins with the same two states · label pills on fixed baselines · route language (dashed = sea/coastal, thin solid = overland). These let anyone read “Machine learning” at a glance.

Personal variation (seeded per person)

Coastline and land structure (one continent / archipelago / basin) · material (terraced grass, faceted crystal, sage with dunes and canyons) · light (crisp daylight terminator, cool glacial with aurora, warm dusk haze and rim light) · landmark glyphs · region arrangement and routes · orbit tilt and order · neighbouring topics.

What landmarks may mean

Decoration drawn from a stable personal seed, placed beside an actual region. They never encode amount watched, recency or any score. Region pins map 1:1 to supported regions; terrain size never implies more evidence.

Commands · observations

OBS universe.open · universe.select{planet}
CMD visit.open{handle} when viewing a friend
The seed and materials are part of the scene descriptor, so the same person sees the same world on every device.

Restore

Each person’s camera {system, planet, rotation, zoom} is stored for their own universe only. A visit always opens a friend’s world at its default framing; nothing about the visitor’s camera is saved in the friend’s scene.

Accessibility & platform

Identity is carried by shape, texture and light, not hue alone (grayscale test: archipelago vs continent vs basin still differ). List view stays identical across people. Reduced motion: no aurora shimmer or haze drift. 2D layered SVG/Skia-feasible; no 3D required.
