R01

Cosmic room preview

A room is a station in your own geography. One room, one identity — but it sits wherever it fits on each person’s map. No activity counts.

Prototype · design data

Route & origin

Tap the station in /universe or /universe/:system → card → /room/:roomId. Also reachable from Talk (C01). Same room ID everywhere; only its map placement is personal.

Actions

Primary: Enter / Join room. Secondary: close card, list view, read guidelines, message a friend for an invite, read a paused room.

States & overlays

card · preview · open · invite-only · paused · removed from room (“You’re no longer a member”) · room closed · offline (cached preview, Join disabled with reason). No member, active or online counts.

Commands · observations

CMD room.join{roomId}
CMD room.request_invite{roomId}
OBS universe.select{stationId} · room.preview_opened
Joining or visiting a room is never encounter evidence; it can’t form or grow a world.

Restore

Back from the preview returns to the map with the same camera and the station card still open. Leaving the room returns you to where you entered it (map or Talk).

Accessibility & platform

The station is a 48px button named “Model serving room, a room”. List view lists rooms under their systems. Roles are spoken as text (“AI, Explainer”). On desktop the preview docks as the D02 station card.
