Annotation vocabulary used on every sheet
MarkMeaning
CMD nameDurable command with stable request ID (save, send, choose branch). Server receipt is authoritative.
OBS nameObservation summarised by the shared recorder (visible interval, block coverage). Never counts as a command.
GestureWhich layer owns the pointer: article, component, thread, platform back.
RestoreWhat is reinstated on return: anchor, playhead, branch node, camera.
PlatformRN native vs React Native Web differences (back, text selection, share, keys).

Status is never colour alone: every state pairs a glyph and a word (✓ Sent, ↻ Retry, ⌁ Offline, ⧗ Preparing).
