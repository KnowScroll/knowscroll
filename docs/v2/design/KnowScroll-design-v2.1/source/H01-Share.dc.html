H01

Share sheet

“Here’s something interesting. Come explore it with me.” The same sheet on Reels and Scrolls: send it to a chat, start a content thread with friends, share an exact moment, or take a link elsewhere.

Prototype · design data

Route & origin

Overlay opened from Share on any Reel or Scroll (rail, strip, ⋯ menu, desktop popover). Not a history entry: Back or swipe-down closes it and a Reel that was playing resumes. “Explore with friends” lands in /thread/:threadId (C04).

Actions

Primary: Explore with friends → Create thread. Secondary: Send to a conversation, Share a moment (H03), Copy link / system share. A thread can start from a single Reel or Scroll — no series needed.

States & overlays

sheet · picking (0 selected disables Create) · creating (busy) · created → thread · sent (receipt) · send failed → retry same request · copied · system share opened · cancelled (silent) · content withdrawn / private (blocked before any send).

Commands · observations

OBS share.sheet_opened · share.sheet_cancelled · share.link_copied · share.system_opened
CMD share.send{conversationId, assetRevision, anchor?}
CMD thread.create{members[], root: assetRevision, name}
External share intent ≠ delivery.

Restore

Closing returns to the same Reel second / Scroll anchor. After Create, Back from the thread returns to the encounter you shared from, at its position. Draft note text survives switching between the options.

Accessibility & platform

Options are buttons with full names; picker rows are labelled checkboxes. Presence is a word, set by each person in F02 — people who hide it show none. Native: system share sheet. Web: Web Share API, falling back to copy.
