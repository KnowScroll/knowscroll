U06

Friend universe visit

Ravi’s Machine learning is recognisably ML but unmistakably his: crystal archipelago, glacial light, aurora, a debris ring around Hardware. Private parts are never drawn — one generic haze, identical for every visit, and a plain banner.

Prototype · design data

Route & origin

/visit/ravi.m from a friend row (F01), a share card, or a room member. Requires Ravi’s visibility setting (F02) to include Asha; otherwise the denied state shows directly.

Actions

Primary: look around, open a shared system. Secondary: enter the shared room, Leave (always visible), open conversation, read the privacy banner. Visitors never see Ravi’s encounters or history.

Generic privacy rule

Hidden systems are simply not in the scene the visitor receives. The edge haze is one fixed decoration, identical for every visit and every person; the banner shows whenever any visibility limit applies, so neither reveals location, size or whether anything is hidden.

Commands · observations

CMD visit.open{handle} · room.join{roomId}
OBS visit.select{system}
The visitor scene is server-filtered; private bodies never reach the client. Visiting creates no evidence for either person.

Restore

Leave and Back return to the exact camera of your own universe. Ravi’s camera position isn’t stored beyond the visit. The shared room keeps one identity; each map keeps its own placement.

Accessibility & platform

Visitor bar is a landmark announced on entry (“Visiting Ravi, only what he shares”). The privacy banner is a real button. Leave is first in Tab order. List view works as in U02, listing only shared systems.
