C01

Conversation inbox

Real conversations only: people, content threads and rooms. Optional “Online” / “Recently active” labels show availability, never what anyone is watching. No activity counts.

Prototype · design data

Route & origin

/talk tab root. Reached from the nav, a “Sent to Ravi” toast, a message notification, or a room station in the universe. Rows link to /talk/:conversationId, /thread/:threadId, /room/:roomId.

Actions

Primary: open a conversation or content thread. Secondary: new message / new thread, long-press row for Mute / Leave. Thread rows show only your position (“You: Part 2”). Presence labels are optional, set in F02, and say availability only. No pinned AI chat, no suggested strangers.

States & overlays

loading (row skeletons) · ready · empty · offline (cached, dimmed, “may be out of date”) · reconnecting (same banner, “Reconnecting…”) · queued outgoing count from the real local queue.

Commands · observations

CMD conversation.open{conversationId}
CMD conversation.mute / leave · thread.mute / leave
OBS talk.list_viewed
Presence: coarse server state (online / recently active / hidden) honouring each person’s setting.
Notification setting is per conversation; unread derives from the server read cursor.

Restore

Returns to the same scroll position in the list. Opening a conversation lands at the first unread message, otherwise the last position read. Threads reopen at your own item and playhead plus the conversation position; rooms keep theirs.

Accessibility & platform

Each row is one link with a full accessible name (“Ravi, unread, shared a Reel…”). Unread uses dot + bold weight, not colour only; presence is a word (“Online”), the dot is decoration. Rooms use a square station glyph so they never read as a person; AI never appears as a row. Web: ↑/↓ moves between rows.
