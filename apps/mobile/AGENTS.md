# Android ownership

Read the root instructions, docs/product/design-direction.md and docs/contracts/bootstrap-http.md. Native Kotlin/Compose; only Reel | Scroll consumption objects. Bootstrap implements only sourced Scrolls and explicit keeps. Models and provider keys never belong here.

Keep navigation origin and retry envelopes stable. Record exposure from a resumed, visibly drawn screen, never prefetch. Non-2xx is not success; retry the same key and payload after ambiguity. Never infer a planet or learning from a keep. No fake data outside tests.

Run Gradle assembleDebug/lintDebug plus the relevant real emulator journey. Build success alone does not prove UI behavior. Read README for current limits. Debug local token is generated in ignored local.properties. A release build refuses until the owner's signing and API inputs are given (ADR-0047, docs/operations/release-inputs.md); never commit a keystore or release.properties.
