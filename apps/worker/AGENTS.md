# Worker ownership

Own short deterministic projections and separate development certification tooling. Ordinary provider execution remains future work. Current project_keep runs within one transaction and makes no external calls. SKIP LOCKED distributes work, not exactly-once external side effects. AI SDK adapters, attempts, reservations, leases/fences, cancellation and stale proposal gates require the reasoning runtime issue before paid calls. Provider keys only here. Cutroom host paths are not mobile URLs; imported assets need KnowScroll provenance and publication gates.

Lock the universe before the job, including failure settlement. Re-read a selected candidate under that lock; privacy clear can remove it before acquisition. Check universe/job/Ledger epochs before applying. Stale work is discarded, never reported completed. Read ADR-0009/0010 before changing privacy behavior. Deterministic keep additions are not semantic model proposals and do not require a blanket Accounts-revision equality gate.

ADR-0011 permits only the explicit bounded certification CLI: fixed synthetic cases, subscription quota preflight, one fsynced attempt before each request, no retries or resume, and sanitized receipts. It does not enable the ReasoningProvider product port. Keep raw native thinking/tool blocks only in protected process memory; no credentials or provider errors in logs. Certification workers receive no live credentials; coordinator owns live execution.

Read ADR-0012 before reasoning-runtime work: separate private execution and retained minimal accounting identities; universe-first locks; consumed dispatch intents are never replayable. A late old-epoch receipt may settle original accounting without private output authority. Exact history-clear receipt replay returns before any reasoning/accounting mutation. The protocol and metadata schemas are accepted; database admission and J004 are still unimplemented.
