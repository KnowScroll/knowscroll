# Worker ownership

Own short deterministic projections, separate development certification tooling, and two product provider paths: Scroll Ask answers (ADR-0033, `src/reasoning/answer-worker.ts`) and background bridge inquiries (ADR-0038, `src/reasoning/inquiry-worker.ts`; the worker opens due inquiries itself, and a reply changes state only through `submitBridgeProposal`), both only through the ADR-0019 plane (fair admission, one invocation, reconciliation) with the key from this process's environment. When the inquiry route shares the answer route's scheduler, either loop runs whatever claim fairness admitted with that claim's own family path. Current project_keep runs within one transaction and makes no external calls. SKIP LOCKED distributes work, not exactly-once external side effects. AI SDK adapters, attempts, reservations, leases/fences, cancellation and stale proposal gates require the reasoning runtime issue before paid calls. Provider keys only here. Cutroom host paths are not mobile URLs; imported assets need KnowScroll provenance and publication gates.

Lock the universe before the job, including failure settlement. Re-read a selected candidate under that lock; privacy clear can remove it before acquisition. Check universe/job/Ledger epochs before applying. Stale work is discarded, never reported completed. Read ADR-0009/0010 before changing privacy behavior. Deterministic keep additions are not semantic model proposals and do not require a blanket Accounts-revision equality gate.

ADR-0011 permits only the explicit bounded certification CLI: fixed synthetic cases, subscription quota preflight, one fsynced attempt before each request, no retries or resume, and sanitized receipts. It does not enable the ReasoningProvider product port. Keep raw native thinking/tool blocks only in protected process memory; no credentials or provider errors in logs. Certification workers receive no live credentials; coordinator owns live execution.

Read ADR-0012 before reasoning-runtime work: separate private execution and retained minimal accounting identities; universe-first locks; consumed dispatch intents are never replayable. A late old-epoch receipt may settle original accounting without private output authority. Exact history-clear receipt replay returns before any reasoning/accounting mutation. Migration 0004 and reasoning-storage.ts implement storage, history-clear erasure, restricted receipt append and bounded retention cleanup. Read docs/operations/reasoning-storage.md for caller transactions and remaining limits. Migration 0005 and the admission/reconciliation factories implement atomic development primitives. Read docs/operations/reasoning-runtime.md before consuming them: trusted resolver/context callbacks, immutable input/policy bindings, cumulative usage and no replay after ambiguous commit. J004 verifies synthetic process faults; product dispatch remains disabled. ADR-0015 below adds separate scheduled cleanup for safely withdrawn Jobs.

Migration 0006 and `reasoning-fairness.ts` implement internal durable fair admission. Read `docs/operations/reasoning-sql-fairness.md`: one probe transaction, universe-first locks, scheduler generation fencing, complete vector preflight, retained cross-epoch debt and immutable private ready rows. Shared scheduler resources lock before physical buckets; product dispatch remains disabled.

Migration 0008/ADR-0015 define seven-day retirement only for safely withdrawn cancelled/expired Jobs. Read `docs/operations/reasoning-retirement.md`. Preserve the authoritative withdrawal clock, original live-lease requirement, immediate Clear History, and separate all-duties-closed accounting retention. The maintenance entrypoint is separate from projection; it must not release unknown liabilities, infer timestamps or broaden withdrawal authority.

ADR0020 governs the unwired Cutroom HTTP client. Preserve the upstream schema revision/hashes, prepared bytes/identity, explicit uncertainty, bounded loopback transport and source/status/cursor checks. The HTTP client grants no funding or publication authority; host paths remain untrusted metadata. Do not connect it to ordinary jobs or relax transport without the scoped demand, privacy, import and bounded-live-verification contracts.

ADR-0041: model-written Scrolls (`src/scrolls/`). `fetch-material.ts` checks every URL and redirect hop against `material-hosts-v1` before requesting it, and sends no cookie or credential. `write-scroll.ts` sends one request per undecided (material, request) pair through the caller's transport and `beforeSend` gate, never retried, and admits only what `scroll-checks-v2` passes. Its only live caller is the operator CLI `scripts/scrolls/write-scrolls.ts` (quota preflight and the session ledger before each request); a worker loop with an operator-installed route is #164.
